# Indian State Lottery Draw Schedule — Open Dataset (2026)

A machine-readable schedule of government lottery draws across 13 Indian states: draw names, timings (IST), ticket prices, first-prize amounts, and official result sources.

## Files

- `draw_schedule_2026.csv` — the full schedule (state, draw name, draw time, days, ticket price, first prize, official site)

## Why this exists

Lottery result data in India is fragmented across a dozen state websites, most of them slow or hard to scrape. This dataset gives developers, researchers, and journalists one clean table to build on.

For live results updated within minutes of each draw, see **[Lucky Sambad](https://luckysambad.in/)** — a free result portal covering all 13 states with a ticket checker tool.

## Data notes

- Timings are indicative and can shift on public holidays or special bumper draws.
- Prize amounts are the advertised first prizes; always verify against the official PDF before claiming.
- This is a reference dataset, not a result source. For claiming prizes, only the official state lottery PDF counts.
